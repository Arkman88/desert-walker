# Ящик v4

`desert_crate_v4.glb` — извлечённые четыре узла `decorative_crate_*` из
`../desert_hut_v4/desert_hut_v4.glb`, с исходными материалами и текстурами.
Это существующая модель, без нового моделирования.

Обновление из исходника: `python3 scripts/extract_hut_crate.py` из корня проекта.

`features/resources/crateAsset.ts` применяет то же исправление UV, что используется
в хижине, и нормализует меши под существующие размеры коллизий. Повторяющиеся
ящики объединены по материалам и отображаются через instancing. Пул ресурсов
разделяется миром, декоративными ящиками улицы, установкой и предпросмотром крафта;
последний пользователь освобождает геометрии, материалы и текстуры.
