# Desert Walker — хижина v4 (мелкий саман без повторяющегося каменного узора)

Файлы:
- `desert_hut_v4.glb` — лёгкая текстурированная хижина, Y вверх, пол на Y=0, вход в направлении -Z. Габарит корпуса 5.2 × 4.2 × 2.85 м, плюс боковой навес.
- `crate_visual.glb` — отдельная визуальная модель ящика (исходное смещение относительно центра хижины сохранено: примерно x=-3.62, z=-0.72). При самостоятельном использовании сбросьте смещение через обёртку/перенос геометрии.
- `textures/` — 5 цветовых PNG, использованных внутри GLB; текстуры уже встроены в GLB.

Обновление v4: процедурный мелкозернистый саман без крупных повторяющихся пятен, продольная текстура брёвен без тёмных полос, программная проверка границ PNG. Изменения v2: более светлые и менее контрастные материалы, реальные проёмы окна и двери, деревянные оконные рамы, детали двери, цилиндрические брёвна с UV вдоль оси, сетчатая провисающая ткань с неровным краем, отдельные именованные элементы. Карты normal/roughness **не добавлялись**, поскольку исходные карты атласа не были проверены как физически корректные и давали риск артефактов. Материалы имеют высокий roughness.

Важно: это **улучшенная стилизованно-реалистичная low-poly модель**, а не фотореалистичная копия концепт-арта. Саман по-прежнему геометрически простой; отдельные мелкие трещины представлены текстурой. На реальный результат сильно влияют свет, экспозиция, тонмаппинг и UV.

## Codex / Three.js

1. Положите GLB в `public/models/huts/` и загрузите через `useGLTF`.
2. Уберите старую геометрию хижины; не размещайте два ящика в одной точке. Узлы `decorative_crate_*` можно скрыть и заменить действующим игровым ящиком с E, лутом и разборкой.
3. Узел `door_leaf_*` пока статичен. Для анимации создайте шарнир у боковой кромки и перенесите туда дверь и её накладки, либо замените существующим интерактивным объектом.
4. Используйте простые коллайдеры для стен, крыши, стоек и закрытой двери. **Не ставьте сплошной коллайдер на весь дом**: проёмы должны быть доступны.
5. Base color текстуры в GLB — sRGB; не умножайте их дополнительно на тёмный цвет. Проверьте `renderer.toneMapping`, `toneMappingExposure`, directional/ambient light. Для пробного просмотра выставьте нейтральный дневной свет и проверьте дом с разных сторон.
6. Встроенные материалы не требуют повторного назначения текстур. Сохраните генерацию, взаимодействия, физику и сохранения существующей игры.
7. Сначала протестируйте одну хижину и FPS, затем заменяйте остальные варианты.
